# Drills

Output drills for what doesn't fit on a card: patterns of register and structure that have to be
produced under pressure (formal inversions, hedging, nominalization, sentence variety). One file
per session: `YYYY-MM-DD-<pattern>.md`. Each item traces back to something the student wrote.

Remember the order: **the student produces first, the explanation comes when they ask.**
