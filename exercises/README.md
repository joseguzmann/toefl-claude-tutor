# Exercises

One clean page per exercise, grouped by day: `exercises/YYYY-MM-DD/<task>-<topic>.md`.

**An exercise page has only what would be printed on an exam sheet:** instructions, prompt, time,
space to answer. Answers go hidden inside `<details>`. After the student finishes, the result is
added **below** the answer, together with the full prompt, so it can be reviewed later.

Generated prompts are marked `[generated]` in the title so they're never confused with an
official one when reporting a measurement.

Prefer Notion? Tell the tutor; it will create the pages there instead, with the same rules.
