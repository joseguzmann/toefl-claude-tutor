# Audio prompts

Each audio exercise is cut into single questions, without the student's answers, so it can be
practiced again. **A reused prompt trains; it never measures.**

```
audio/prompts/
  take-an-interview/2026-09-08-gardening/p1-green-spaces-neighborhood.m4a
  listen-and-repeat/2026-09-21-library/03-return-books-desk.m4a
  academic-talk/2026-10-18-gothic-literature/talk.m4a
```

- Number + content slug; the date is in the folder name.
- AAC 64 kbps, cut from the original recording (not the 16 kHz WAV used to transcribe).
- Every cut is verified by transcribing it before it's kept.
- ETS audio is copyrighted: this folder is fine for your private copy, but don't publish it.
